# ThodShot

Лёгкая программа скриншотов для ThodHUB (Windows x64, standalone).

- **PrintScreen** сразу открывает затемнённый выбор с верхней панелью: «Область» (по умолчанию), «Весь экран», крестик. Esc или правая кнопка — отмена, Enter — весь экран.
- После снимка — окно предпросмотра: колесо мыши — масштаб от курсора, перетаскивание — сдвиг, вписывание в окно при отдалении.
- Пометки: красная стрелка, ромб и маркер. Первый клик задаёт начало, второй фиксирует фигуру; правая кнопка отменяет незакреплённую, Ctrl+Z убирает последнюю. Пометки попадают в скопированное и сохранённое изображение.
- Кнопки внизу сгруппированы: слева распознавание текста, справа копирование, сохранение (главная) и настройки.
- «Сохранить»: файл в `Изображения\Скриншоты` (папка меняется в настройках), открывается проводник с файлом, картинка копируется в буфер. Повторное сохранение обновляет файл с новыми пометками.
- «Распознать»: локально (встроенный OCR Windows, без интернета). Слова подсвечиваются на снимке, их можно выделять мышью и копировать (Ctrl+C, двойной клик — строка, тройной — всё). Выделение сохраняется при масштабировании.
- Захват идёт через Windows Graphics Capture с резервным BitBlt, поэтому видны аппаратно ускоренные окна (VMware и подобные).
- Программа живёт в трее, хаб для снимков не запускается. Настройки: «Открыть» в хабе, кнопки действий в карточке или значок в трее.

## Сборка и выпуск

1. Версия задаётся в `src/ThodShot/ThodShot.csproj` и `hub/manifest.json`.
2. Каждый push в `main` с изменениями в `src/` или `hub/` запускает `.github/workflows/release.yml`: сборка, упаковка `package-module.ps1`, проверка `validate-package.ps1`, release `hub-vX.Y.Z`. Если release этой версии уже есть, шаг пропускается.
3. Шаблоны изображений для каталога: `registry/assets/thodshot.svg` и `registry/assets/icons/thodshot.svg`. Сам каталог живёт в `ThodProd/ThodHUB-Registry`; запись `thodshot` уже добавлена.

## Проверено

- `dotnet publish` (net8.0-windows, win-x64, self-contained, single-file) собирается без ошибок.
- `package-module.ps1` + `validate-package.ps1`: манифест, размер, SHA-256 и распаковка пакета проверены.
- Запуск `--background` и остановка `--stop-background` работают.
- Захват экрана, оверлей выбора и окно предпросмотра проверены вручную на Windows 11 (2560×1440).
- Тёмная тема, виньетка по краям и перезапуск для смены темы проверяются вручную.
- OCR, сохранение файла и реакция системы на PrintScreen проверяются пользователем на его машине.
