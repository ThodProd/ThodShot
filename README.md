# ThodShot

Программа для снимков экрана на Windows x64. Начиная с версии 1.2.0, ThodShot собирается на Rust и работает без .NET. ThodHUB устанавливает и обновляет приложение. Снимки можно делать, когда хаб закрыт.

- **PrintScreen** открывает выбор области. «Весь экран», Enter или Space снимают монитор под курсором. Esc и правая кнопка отменяют захват.
- В предпросмотре колесо мыши меняет масштаб относительно курсора. В режиме «Курсор» перетаскивание сдвигает увеличенный снимок. Стрелку, прямоугольник, выделитель и маркер можно рисовать левой кнопкой мыши. Правая кнопка отменяет незавершённую пометку, Ctrl+Z отменяет последнее действие, Ctrl+Y или Ctrl+Shift+Z повторяет его.
- **«Распознать»** запускает Windows OCR локально. Двойной клик выделяет строку, тройной клик или Ctrl+A выделяет весь текст. Ctrl+C копирует выделенный текст или снимок с пометками. При включённой подсветке текста Alt+перетаскивание сдвигает снимок.
- **«Сохранить»**, Enter или Space сохраняют PNG или JPEG, копируют изображение и закрывают предпросмотр. Ctrl+S сохраняет снимок и оставляет окно открытым. Esc закрывает предпросмотр без сохранения. Повторное сохранение обновляет файл. Папка по умолчанию находится в «Изображения → Скриншоты».
- **«Настройки»** доступны из карточки ThodHUB, предпросмотра и меню трея. Тема меняется сразу. Значок в трее по умолчанию скрыт. Настройки предыдущих версий сохраняются при обновлении.

## Сборка и выпуск

В Windows с Rust и набором средств C++ для Visual Studio выполните:

```powershell
cargo test --locked
cargo build --locked --release
```

Исполняемый файл находится в `target/release/ThodShot.exe`. Для проверки захвата на интерактивном рабочем столе запустите `cargo test --locked -- --ignored`.

Версия задаётся в `Cargo.toml` и `hub/manifest.json`. Обновите `Cargo.lock` и описание выпуска в `hub/notes.txt`. GitHub Actions собирает Windows x64 EXE, упаковывает и проверяет его скриптами ThodHUB, затем публикует ZIP и `thodhub-release.json` в релизе `hub-vX.Y.Z`. ThodHUB получает обновление из этого релиза.

См. [совместимость Rust-версии](rust/README.md).
